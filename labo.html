CE QUE FAIT LE LABO

  • Détection passive : il écoute ce qui passe (Wi-Fi, annonces Bluetooth), sans rien émettre.
  • Rien d'inventé : ce qui n'est pas mesuré est affiché « inconnu ».
  • La distance est une estimation tirée du signal ; l'angle sur le radar est arbitraire.
  • Les adresses MAC des appareils des autres sont masquées.

CE QUI RESTE INTERDIT

  • Toute action sur un appareil qui n'est pas à nous (lecture seule).
  • 4G / 5G, brouilleur, EMP, désauthentification : jamais.
  • Le pentest se lance seulement depuis le PC, via le garde et la liste blanche.

SUR LE TÉLÉPHONE

  • Les mesures viennent du PC (sa carte Wi-Fi et son Bluetooth), avec la clé de ce téléphone.
  • Rien n'est gardé dans le téléphone ni publié : la page ne contient aucune donnée.
  • PC éteint ou hors réseau : « Besoin du PC allumé ».
